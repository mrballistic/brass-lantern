## Global Constraints

- Fidelity is the gate: the full engine suite (`npm test -w @brass-lantern/engine`), including `zork1-diff`, `zork1-full`/`-chapters`/`-rooms`/`-sessions`/`-fight`/`-thief*`, `zork1.test.ts`, `zork2-slices`, `zork3-slices`, stays green after every task. A Zork test that loses a name match gets an alias in that world, never a looser rule; list every alias added in the task report.
- Defaults don’t change behaviour for existing worlds, except the two deliberate changes: the fuzzy token tier (Task 1) and EXAMINE of a character in the dark (Task 6).
- Misses (`understood: false`) must not mutate state.
- Player-facing lines use smart punctuation (“ ” ’). Exact new lines: FOLLOW at a character with no rule: `You’d rather ${The name} came to you. Try ${NAME}, FOLLOW ME.`; FOLLOW at a thing: `You can’t follow that.`; bare FOLLOW: `What do you want to follow?`; LIGHT on a non-switchable flaming item: `It’s already lit.`
- The save format version (`SAVE_VERSION = '2.0'`) doesn’t change.
- Release: all versions 2.1.0 (root, `packages/{engine,vue,server}`, `apps/site`, `packages/engine/src/version.ts`), vue’s engine range `^2.1.0`. Don’t tag or publish; the owner approves.
- Never read, print or commit `.env` files; exclude them from every search. Never delete the untracked `tests/zz/`.

## Review Focus

1. A player typing a short name that used to resolve through a partial match (“take lamp”, “kill troll with sword”, “cube farm”, “red stapler”) still gets the thing they meant; only names with an unmatched extra word stop resolving. (Task 1: the Zork suite plus an explicit list of short-name cases.)
2. Compound input still splits normally when no name contains “and” (“take lamp and sword”, “n. e. take all”), and a name containing “and” stays whole even inside a longer compound line. (Task 4 test.)

5. Words like “constructor” and “__proto__”, typed bare, as a direction (“go constructor”), as a topic or as an order, never throw or crash a turn. (Task 2 test.)

```ts
/** Every typed word of three or more letters must match one of the candidate’s tokens. */
function coversAll(needleTokens: string[], haystack: string[]): boolean {
  return needleTokens.filter((t) => t.length >= 3).every((t) => tokenPrefixScore([t], haystack) > 0);
}
```
